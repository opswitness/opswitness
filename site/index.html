ONE SIMPLE LOOP

From a goal to work you can run again.

OpsWitness sits above your AI runtimes. It makes the team, process, decisions, and results visible without asking you to operate the underlying control planes.

  1. 1

    Describe the outcome

    Start from a goal, a proven template, or an earlier planning conversation.

  2. 2

    Review the AI team

    See roles, reporting lines, stages, model choices, and human checkpoints.

  3. 3

    Confirm and run

    Execution starts only after an immutable plan version is reviewed and confirmed.

  4. 4

    Reuse what worked

    Open readable results, inspect evidence, rerun, fork, or revise the architecture.

BUILT FOR REPEATABILITY

Run history

HONEST ALPHA BOUNDARIES

Useful now, explicit about what is not ready.

Included in the Alpha candidate

  • Local single-operator Workspace and Work UI
  • Plan review, immutable revisions, rerun, and fork
  • Team execution with input and approval checkpoints
  • Pause, continue, stop, History, Results, ledger, and CAS
  • Built-in repeatable-work templates and reviewed Workspace Memory

Not promised in this release

  • Stable durability, SLA, or unattended critical operations
  • Hosted SaaS, multi-user accounts, or a mobile app
  • OpenClaw, Work-calling-Work, or silent autonomous learning
  • Tax filing, customs filing, insurance advice, or other licensed decisions
  • DeepSeek or Grok execution adapters
  • A downloadable package before the release evidence gate passes

COMMUNITY ALPHA AVAILABILITY

One verified package, when the evidence is ready.

OpsWitness will be distributed through a GitHub prerelease, not PyPI. Until that prerelease exists, this page will not offer an unverified download.

What the release will include

  • Python wheel and source archive built from the tagged commit
  • SHA-256 checksums and a machine-readable build manifest
  • SPDX software bill of materials and GitHub attestation
  • A blank-install smoke test before the download link goes live

The first package targets macOS 14+ with Python 3.12. Start with synthetic or non-critical work; durability remains experimental in Alpha.

Release candidate validation in progress

The download button will appear only after the exact public build passes the release checks. No email signup or hosted account is required.
