HONEST ALPHA BOUNDARIES

Useful now, explicit about what is not ready.

Included in Community Alpha

  • Local single-operator Workspace and Work UI
  • Plan review, immutable revisions, rerun, and fork
  • Team execution with input and approval checkpoints
  • Pause, continue, stop, History, Results, ledger, and CAS
  • Built-in repeatable-work templates and approved Workspace Memory

Not promised in this release

  • Stable durability, SLA, or unattended critical operations
  • Hosted SaaS, multi-user accounts, or a mobile app
  • OpenClaw, Work-calling-Work, or silent autonomous learning
  • Tax filing, customs filing, insurance advice, or other licensed decisions
  • DeepSeek or Grok execution adapters

INSTALL ON YOUR MAC

Drag to Applications. Run your first Work.

Community Alpha is distributed as an ad-hoc signed Apple Silicon Mac App through GitHub Prerelease. It is not notarized, so macOS may require right-clicking the App and choosing Open on first launch.

  1. Download the DMG and verify its checksum.
  2. Drag OpsWitness into Applications.
  3. Open it and sign in to Codex with your own account.
  4. Turn a fictional customer inquiry into a reviewed reply draft.

Python, Node, PostgreSQL, Paperclip, AionCore, Codex CLI, and managed runtime components are included. Start with the built-in customer example, which has no delivery step.

One download. No dependency setup.
