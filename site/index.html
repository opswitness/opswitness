HONEST ALPHA BOUNDARIES

Useful now, explicit about what is not ready.

Included in Community Alpha

  • Local single-operator Workspace and Work UI
  • Plan review, immutable revisions, rerun, and fork
  • Team execution with input and approval checkpoints
  • Pause, continue, stop, History, Results, ledger, and CAS
  • Built-in repeatable-work templates and approved Workspace Memory

Not promised in this release

  • Stable durability, SLA, or unattended critical operations
  • Hosted SaaS, multi-user accounts, or a mobile app
  • OpenClaw, Work-calling-Work, or silent autonomous learning
  • Tax filing, customs filing, insurance advice, or other licensed decisions
  • DeepSeek or Grok execution adapters

INSTALL ON YOUR MAC

Start with a local evidence run.

Community Alpha is distributed through a signed GitHub prerelease, not PyPI.

  1. Install Python 3.12 and uv.
  2. Install the wheel from the GitHub Release.
  3. Run one synthetic wrapped command.
  4. Open the local Workspace at 127.0.0.1.

Start with synthetic or non-critical work. Full team execution additionally needs compatible local AionUi and Paperclip services. 

uv tool install --with mcp \
  https://github.com/opswitness/opswitness/releases/download/v0.1.0-alpha.1/opswitness-0.1.0a1-py3-none-any.whl

opswitness version
opswitness wrap --job hello -- /usr/bin/true
opswitness console serve --open
