OpsWitness macOS application third-party notices
=================================================

This file describes the pinned runtime families intended for the
OpsWitness 0.1.0-alpha.1 macOS arm64 application. The authoritative
artifact versions, source URLs, hashes, architectures, and redistribution
review status are recorded in desktop/vendor-lock.json and the release SBOM.
If those records are incomplete, the public release workflow must fail.
