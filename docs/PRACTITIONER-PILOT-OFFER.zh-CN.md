# 本地 AI 命理师工作台：付费设计伙伴计划

版本：2026-07-13 · 对外使用中性项目名称，正式品牌待定

> 这是一份 30 天付费 Pilot 的商业确认模板，不替代律师审核的正式合同、隐私政策
> 或数据处理协议。双方可通过签署文件或明确回复本文件全部条款的邮件完成工程启动
> 闸门。

## 一句话说明

在命理师自己的 Mac 上部署一套本地工作台，把“客户登记、确定性排盘、知识检索、
AI 草稿、引用检查、人工审签、品牌 PDF 和可追溯归档”串成一个流程。系统帮助整理与
起草，不替代命理师判断，也不会自动把报告发送给客户。

## 适合谁

- 已有稳定客户来源，每月需要制作多份书面解读；
- 希望减少重复排盘、查资料和排版时间，但保留最终审签权；
- 愿意提供自己的知识笔记和报告样式，共同打磨专业工作流；
- 接受使用自己的 Anthropic API key，并愿意完成必要的云处理告知与同意。

不适合只想要“无人值守自动算命”、流量获客工具、微信小程序或多人 SaaS 的团队。

## 30 天交付范围

1. 在一台指定 Mac 上完成白手套安装，仅绑定 `127.0.0.1`，由 launchd 启动。
2. 使用固定版本 `lunar-python` 完成确定性排盘，并用双方确认的 golden cases 验证。
3. 导入一套 Obsidian Markdown 知识库；使用严格 frontmatter、FTS5 检索和签名知识包。
4. 提供客户登记、排盘、检索、AI 草稿、引用/eval、人工审签、PDF 和归档工作流。
5. 配置一个品牌 PDF 模板，并完成至少 10 份真实、付费、由命理师审签的报告。
6. 提供数据导出、客户删除、保留期限设置和本地备份/恢复说明。
7. 在 Pilot 期间提供两次工作流复盘；修复阻塞性缺陷并记录需求取舍。

首期不包含多租户、移动 App、微信小程序、云托管、自动客户发送、订阅计费、正式
SLA、向量数据库、客户获客服务或无限量定制。

## 数据与模型边界

- 姓名、联系方式、原始出生日期和时间只保存在命理师 Mac 的本地数据库。
- 这些原始字段不得进入模型请求、Paperclip metadata、日志、Telegram 或 artifact
  metadata。
- 允许发送给模型的内容只有匿名 client ID、确定性派生命盘特征和本次检索命中的
  知识片段。
- 本地业务字段使用 AES-256-GCM、每条记录独立 nonce；主密钥进入 macOS Keychain。
- 模型调用只经过统一 egress builder；自动测试必须证明原始 PII 零出站。
- 命理师负责在收集客户数据前取得适用的云处理同意，并使用娱乐/反思用途说明。
- 客户可申请导出或删除；保留期限由命理师配置，删除动作必须留下不含 PII 的审计证据。

任何要求把原始出生信息、姓名或联系方式直接发送给模型的改动都需要拒绝，而不是
通过免责声明放行。

## 人工责任与质量标准

- 排盘正确性由确定性引擎与 golden tests 判断，不由 LLM 自评。
- 模型只能起草解释；每份报告必须经过命理师人工审签才能生成最终交付件。
- execution evidence 只能证明流程运行；artifact hash、引用、eval 和人工 signoff 才能
  证明报告结果经过验证。
- 产品不承诺“神准”，不提供医疗、法律、投资或其他受监管专业结论。
- 系统不得自动放宽权限，也不得自动把报告发送给客户。

## 双方投入

**产品方提供：**本地安装、约定工作流、数据边界实现、测试、备份说明和 Pilot 支持。

**命理师提供：**指定 Mac、自己的 Anthropic API key、合法来源的知识材料、品牌样式、
golden cases、十个经客户同意的真实案例、及时审签与每周反馈。

双方都不得把真实客户 PII 放入 issue、聊天、测试 fixture、截图或演示资料。用于排障的
案例必须匿名化或合成。

## 知识产权与保密

- 命理师保留其客户数据、原创知识内容、品牌素材和最终报告的权利。
- 产品方保留通用平台、工作流引擎、审计机制和可复用软件模块的权利。
- 未经对方书面同意，任何一方不得公开对方名称、案例、截图、收入或 Pilot 结果。
- 合作结束后，命理师可导出业务数据；产品方不得保留客户原始 PII 副本。
- 正式合同应进一步明确许可范围、保密期限、责任限制与适用法律。

## Pilot 成功标准

30 天结束时必须同时满足：

1. 至少 10 份真实报告走完确定性排盘、引用/eval、人工审签和 CAS 归档；
2. 100% 报告有命理师 signoff，引用可追溯；
3. 全部约定 golden tests 通过；
4. 原始 PII 出站为零，artifact 丢失为零；
5. 备份恢复、导出和删除各完成一次演练；
6. Pilot 款项完成支付；
7. 命理师给出继续付费使用、停止或要求下一阶段报价的明确决定。

只统计报告数量、模型文笔或主观“准不准”，都不能替代上述验收证据。
